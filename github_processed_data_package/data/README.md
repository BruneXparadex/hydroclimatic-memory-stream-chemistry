# Processed data package

Frozen analysis inputs for the manuscript **“Hydroclimatic memory in stream chemistry persists beyond discharge and varies with catchment organization.”**

These files are curated from the project's frozen analytical snapshots. Raw laboratory workbooks, internal checkpoints, restart files, credentials, and unrelated project material are intentionally excluded.

## Files

- `MEMORY_ANALYSIS_DATASET_v1.csv` — analysis-ready dataset for hydroclimatic-memory modelling.
- `HYDROCLIMATE_DAILY_MASTER_v1.csv` — daily hydroclimatic forcing used to construct antecedent windows.
- `HYDROCLIMATE_EVENT_ANTECEDENT_WINDOWS_v1.csv` — event-date antecedent hydroclimatic windows.
- `HYDROMETRY_FROZEN_v1.csv` — frozen hydrometric/discharge records.
- `STATION_NETWORK_FROZEN_v1.csv` — frozen station/network attributes.
- `PRIMARY_MEMORY_RESPONSE_PANEL_v1.csv` — pre-specified response panel.
- `CENSORING_POLICY_FINAL_v1.csv` — frozen censoring policy.
- `PARAMETER_DICTIONARY_FINAL_v2.csv` — parameter metadata/dictionary.

## Interpretation note

Antecedent hydroclimatic variables represent shared event-date forcing over the Razuhuillca reference domain and should not be interpreted as station-specific upstream hydroclimate estimates.
